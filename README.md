## 📝 About

**Sec_Project** is a lightweight command-line application written in Python that allows you to:

* 🔒 Encrypt text securely
* 🔓 Decrypt previously encrypted text
* 🔑 Automatically generate and store an encryption key
* 🎨 Display a clean and interactive terminal interface
* ⚡ Work completely from the command line

The project uses the **Fernet symmetric encryption** implementation provided by the `cryptography` library.

> ⚠️ **Note:** This project is primarily intended for learning and experimentation with Python and symmetric cryptography. It should not be considered a production-grade password manager or secure storage solution.

---

## ✨ Features

| Feature              | Description                                            |
| -------------------- | ------------------------------------------------------ |
| 🔐 Encryption        | Encrypt plaintext using Fernet                         |
| 🔓 Decryption        | Decrypt valid Fernet ciphertext                        |
| 🔑 Key Generation    | Automatically creates `Secure.key` if it doesn't exist |
| 💾 Local Key Storage | Stores the generated key locally                       |
| 🎨 Rich Interface    | Uses Rich for terminal formatting                      |
| 🖥️ CLI              | Simple interactive command-line menu                   |
| 🧪 Error Handling    | Handles invalid ciphertext during decryption           |

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Sec_Project.git
cd Sec_Project
```

### 2. Install dependencies

```bash
pip install cryptography rich pyfiglet
```

Or, if you have a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### 3. Run the program

```bash
python main.py
```

## 🚀 Usage

After starting the program, you will see a menu similar to:

```text
=============================================

1. Encrypt Text 📥

2. Decrypt Text 📤

3. Exit 👋

=============================================

Choose ---> 1 / 2 / 3 :
```

### 🔒 Encrypt Text

Choose:

```text
1
```

Then enter your plaintext:

```text
Enter Your Text 📩 : Hello World
```

The program will generate a Fernet ciphertext:

```text
Your Cipher : ---> gAAAAAB...
```

---

### 🔓 Decrypt Text

Choose:

```text
2
```

Then provide the encrypted ciphertext:

```text
Enter The Cipher 🔐 : gAAAAAB...
```

The program will decrypt it using the locally stored key.

```text
Your Clean Text: ---> Hello World
```

## 🔑 How the Key Works

When the program starts, it checks whether:

```text
Secure.key
```

exists.

### If the key does not exist

A new Fernet key is generated automatically:

```python
key = Fernet.generate_key()
```

and saved into:

```text
Secure.key
```

### If the key already exists

The existing key is loaded and used for encryption/decryption.

```text
Program
   │
   ▼
Check Secure.key
   │
   ├── Not Found ──► Generate Key
   │                    │
   │                    ▼
   │               Save Secure.key
   │
   └── Found ─────► Load Key
                        │
                        ▼
                  Fernet Cipher
                        │
              ┌─────────┴─────────┐
              ▼                   ▼
          Encrypt              Decrypt
```

## ⚠️ Important Security Note

The `Secure.key` file is **critical**.

Without the correct Fernet key, ciphertext generated by this application cannot be decrypted.

Therefore:

* ❌ Do not delete `Secure.key` if you need to decrypt existing ciphertext.
* ❌ Do not upload `Secure.key` to GitHub.
* ❌ Do not share the key publicly.
* ✅ Add `Secure.key` to `.gitignore`.

Example `.gitignore`:

```gitignore
Secure.key
__pycache__/
*.pyc
.env
```

If `Secure.key` has already been pushed to a public GitHub repository, **consider that key compromised** and generate a new one.
